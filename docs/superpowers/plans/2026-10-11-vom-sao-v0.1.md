# Vòm Sao v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the retrieved-passage table in the bench's search slot with a star dome that shows each passage's real cosine and rank as a picture, and the answer passage as a gold star at its real rank.

**Architecture:** One pure module computes the projection from data the run already streamed; one React component draws it on a 2D canvas and mirrors every star as an `sr-only` button. No new engine call, no new event field, no three.js. The component slots into `FactView`, which already receives the retrieved fact and the gold chunk ids.

**Tech Stack:** React 19, TypeScript strict, canvas 2D, Vitest + Testing Library, Tailwind semantic tokens only.

**Spec:** `docs/design/vom-sao-v0.1.md` — this plan is its **phase 1** only. Phase 2 (turning a
knob redraws the dome) needs a retrieval preview endpoint the backend does not have.

## Global Constraints

- Workbench route adds at most **120 kB** gzipped JS and **no chunk of it may contain three.js** (`frontend/scripts/check-bundle.mjs`, workbench-v0.1 §10). Currently 30.6 kB.
- Only semantic Tailwind tokens from `app/app.css`; Tailwind's default palette is removed.
- Banned: purple-blue gradients, glassmorphism, emoji as icons, heavy shadows, bloom, glow, sparkle particles (art §1.3).
- UI copy: Vietnamese, sentence case, buttons start with a verb.
- No idle animation loop: draw once per data or selection change (art §1.2 principle 6).
- `prefers-reduced-motion`: no beam sweep, draw the final frame directly.
- Rank and cosine always printed as numbers, never conveyed by position or brightness alone (spec §7).
- Star position is a projection and the UI must say so (spec §7).
- Check 375 px and 1280 px.

## Review Focus

1. **A case with no retrieved fact at all** (L1's starter graph has no search block): the slot must render as it does today, with no dome and no empty canvas.
2. **`ranks[node]` is `null`** (the answer passage is not in that block's ranking at all): the gold star must not be placed at a made-up position; say it was not found.
3. **`gold_chunks` is empty but the case still has ranks** (`ret.boundary_split`: the chunker cut every answer sentence in half, `GoldTrace` already handles this): no gold star, and no crash from indexing an empty list.
4. **Every retrieved item has the same score** (the L3 recorded run has 0.8032 / 0.8004 / 0.7984, and ties are possible): normalising by `max − min` must not divide by zero.
5. **A hidden or trap case is followed**: a live run sends gold for every case (`test_api_runs.py:176`), so the dome must filter by role itself and draw no gold star.

### Task 1: Projection

**Files:**
- Create: `frontend/app/features/workbench/stardome.ts`
- Test: `frontend/app/features/workbench/stardome.test.ts`

**Interfaces:**
- Consumes: `RetrievedItem` from `./schema`.
- Produces:
  ```ts
  export interface Star {
    chunkId: string; rank: number; score: number;
    dieu: number; khoan: readonly number[]; stale: boolean; gold: boolean;
    /** Unit-square projection: x 0..1 across the dome, y 0..1 bottom to top. */
    x: number; y: number;
  }
  export interface Dome {
    stars: readonly Star[];
    /** The answer passage's rank in this block's full ranking, when it is outside `stars`. */
    missingGold: { rank: number } | null;
  }
  export function starField(
    items: readonly RetrievedItem[],
    goldChunks: readonly string[],
    goldRank: number | null,
  ): Dome;
  ```

Angle from the beam axis grows with `1 − score`, normalised across this call's own score range; a tie (`max === min`) puts every star on the axis. `missingGold` is set only when `goldRank` is a number and no star carries it.

- [ ] **Step 1: Write the failing tests**

```ts
const L3 = readRun("article-number-lookup"); // frontend/public/runs, via test-fixtures

it("places the three retrieved passages and keeps their real numbers", () => {
  const dome = starField(retrievedOf(L3, "lib-l3-v01", "vs"), ["f22a1df7"], 72);
  expect(dome.stars.map((s) => [s.rank, s.dieu])).toEqual([[1, 53], [2, 13], [3, 68]]);
  expect(dome.stars[0]?.score).toBeCloseTo(0.8032, 4);
  expect(dome.stars.every((s) => !s.gold)).toBe(true);
});

it("reports the answer passage's real rank when it is outside the pull", () => {
  const dome = starField(retrievedOf(L3, "lib-l3-v01", "vs"), ["f22a1df7"], 72);
  expect(dome.missingGold).toEqual({ rank: 72 });
});

it("marks the answer passage when it was pulled", () => {
  const items = retrievedOf(L3, "lib-l3-v01", "vs");
  const dome = starField(items, [items[1]!.chunk_id], 2);
  expect(dome.stars.filter((s) => s.gold).map((s) => s.rank)).toEqual([2]);
  expect(dome.missingGold).toBeNull();
});

it("shows the rank alone when the chunker split every answer sentence", () => {
  // ret.boundary_split: gold_chunks is empty, the pieces still have a rank (GoldTrace).
  const dome = starField(retrievedOf(L3, "lib-l3-v01", "vs"), [], 72);
  expect(dome.stars.every((s) => !s.gold)).toBe(true);
  expect(dome.missingGold).toEqual({ rank: 72 });
});

it("says nothing about a gold rank it does not have", () => {
  expect(starField(retrievedOf(L3, "lib-l3-v01", "vs"), [], null).missingGold).toBeNull();
});

it("puts tied scores on the beam axis instead of dividing by zero", () => {
  const tied = [item(1, 0.5, 10), item(2, 0.5, 11)];
  expect(starField(tied, [], null).stars.every((s) => Number.isFinite(s.x))).toBe(true);
});

it("keeps every star inside the unit square", () => {
  const dome = starField(retrievedOf(L3, "lib-l3-v01", "vs"), [], null);
  expect(dome.stars.every((s) => s.x >= 0 && s.x <= 1 && s.y >= 0 && s.y <= 1)).toBe(true);
});
```

### Task 2: The dome component

**Files:**
- Create: `frontend/app/features/workbench/StarDome.tsx`
- Test: `frontend/app/features/workbench/StarDome.test.tsx`

**Interfaces:**
- Consumes: `starField`, `Dome`, `Star` from Task 1.
- Produces:
  ```ts
  export function StarDome(props: {
    items: readonly RetrievedItem[];
    goldChunks: readonly string[];
    goldRank: number | null;
    /** False for a hidden or trap case: no gold star is drawn whatever the payload says. */
    showGold: boolean;
    onSelect?: (chunkId: string) => void;
  }): ReactElement | null;
  ```

Returns `null` when `items` is empty. The canvas carries `role="img"` and an `aria-label` reading "{n} đoạn đã kéo" plus, when `goldRank` is known, "đoạn đáp án ở hạng {rank}". Beside it an `sr-only` list gives one `<button>` per star, labelled "Điều {dieu} khoản {khoan}, hạng {rank}, cosine {score}", and stale passages add "văn bản hết hiệu lực". Canvas drawing happens in an effect keyed on the projection and on `matchMedia("(prefers-reduced-motion: reduce)")`; there is no animation frame loop.
